# 写真の監査表（2026-09-27）

店舗から提供された写真（`assets-src/`、41枚）を1枚ずつ開いて確認した結果。
ファイル名ではなく、写っている内容で判断している。**架空の写真・フリー素材・AI生成画像は使わない。**

## 全体の傾向

- 人物が写っている写真のほとんどは、**名札をつけた参加者が集まったイベント時**のもの。普段の営業の様子ではないので、使う場合はキャプションで「イベント開催時」と書く。
- **2人で遊んでいる写真、スタッフがルールを説明している場面、1人客、建物の外観はない。**
- 店舗の特徴として挙がっている **青系のソファ・天井から吊られた惑星・青/紫/緑の照明は、どの写真にも写っていない**（TwiPla の告知に「スペース改装に伴いプレイスペースを拡張」とあり、改装後の空間の可能性）。
- 客の顔がはっきり写っている写真が多い（自撮り・集合写真）。**掲載の同意を店舗に確認すること。**

## シーンページのヒーロー

同じ写真を複数のシーンページのヒーローに使わない（`scripts/check-games.mjs` が確認する）。合う写真がないページは写真を置かない。

| ページ | 写真 | 理由 |
|---|---|---|
| 雨の日・室内 | room-daytime-wide | 室内で過ごせることが伝わる昼の全景 |
| デート | room-empty | 2人の写真がないため、落ち着いた無人の店内を使う（人物写真は使わない） |
| 友達・グループ | floor-group | 大人数で卓を囲んでいる実写 |
| 1人で | なし | 1人客の写真がない |
| 仕事帰りに | floor-evening | 夜の店内 |
| はじめての方へ | なし | スタッフが説明している写真がない |

## 撮影をお願いしたい写真

1. **2人で向かい合って遊んでいる様子**（デートページ・2人向けの案内に使う。顔が写らない構図で可）
2. **スタッフがルールを説明している場面**（はじめての方へ）
3. **1人で来た人が相席で遊んでいる様子**（1人で）
4. **建物の外観と1階入口**（アクセス。360度でない通常の写真）
5. **中津駅1番出口から店までの道順の要所**（河合塾・公園の角・整骨院）
6. **改装後の店内**（青いソファ・吊られた惑星・照明がわかるもの）
7. **普段の営業時の店内**（イベントではない日の様子）
8. **店が所有するゲームの箱**（ゲーム詳細ページの画像を自社撮影に置き換えるため）

## ゲームの画像

ボドゲーマから取得したパッケージ画像は、同サイトの利用規約（第5条）で運営の事前同意なく転載することが禁じられているため、**2026-09-27に公開を停止**した（ファイルも削除）。
現在はすべてゲーム名から作った表示（`GameTile`）になっている。
店舗で撮影した写真、または権利者から使用許諾を得た画像を `public/games/<slug>-{320,480}.webp` に置き、`src/data/game-images.json` に登録すると表示される。
